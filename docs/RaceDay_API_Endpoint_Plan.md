# RaceDay API Endpoint Plan

Part 1, Section B. Every non-public endpoint depends on an active server-side session created at login, which stores the authenticated user's ID and role. "Owner" in the Role Required column means the endpoint checks that the resource (event or category) belongs to the logged-in Organiser, not just that the caller holds the Organiser role.

Part 3 added four endpoints and widened two existing ones, all marked below: the two image uploads that the MVC front end needs, the Organiser's own event list with enrolment counts for the dashboard, a correction endpoint for results, an upcomingOnly filter on the event list, and the finisher count on a Participant's results so a position can be shown as "47th out of 312". No database columns were added: BannerImageUrl and ProfilePictureUrl were already in the Part 1 ERD and schema.

## Authentication

| HTTP Method | Route              | Description                                                                    | Role Required       | Request Body                        | Expected Response                                                                                                     |
| ----------- | ------------------ | ------------------------------------------------------------------------------ | ------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| POST        | /api/auth/register | Creates a new account and assigns the selected role, Organiser or Participant. | None (public)       | { fullName, email, password, role } | 201 Created with the new user id. 400 Bad Request for invalid input. 409 Conflict if the email is already registered. |
| POST        | /api/auth/login    | Verifies credentials and starts a session for the authenticated user.          | None (public)       | { email, password }                 | 200 OK with the user's role and a confirmed session. 401 Unauthorized for invalid credentials.                        |
| POST        | /api/auth/logout   | Ends the current session.                                                      | Any (authenticated) | None                                | 200 OK. 401 Unauthorized if no session is active.                                                                     |

## User Profile

| HTTP Method | Route                | Description                                                                           | Role Required       | Request Body                                                   | Expected Response                                                                                                               |
| ----------- | -------------------- | ------------------------------------------------------------------------------------- | ------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| GET         | /api/profile         | Returns the logged-in user's own profile.                                             | Any (authenticated) | None                                                           | 200 OK with profile data. 401 Unauthorized.                                                                                     |
| PUT         | /api/profile         | Updates the logged-in user's profile, including the profile picture.                  | Any (authenticated) | { fullName, profilePictureUrl }                                | 200 OK with the updated profile. 400 Bad Request. 401 Unauthorized.                                                             |
| POST        | /api/profile/picture | Uploads a profile picture for the logged-in user and stores it in Azure Blob Storage. | Any (authenticated) | multipart/form-data with a single image file named pictureFile | 200 OK with the updated profile. 400 Bad Request for a missing file, an unsupported type or a file over 5 MB. 401 Unauthorized. |

## Events

| HTTP Method | Route                   | Description                                                                                               | Role Required       | Request Body                                                                           | Expected Response                                                                                                                                           |
| ----------- | ----------------------- | --------------------------------------------------------------------------------------------------------- | ------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET         | /api/events             | Lists all events, with optional filters for date, location, event type or upcoming events only.           | Any (authenticated) | None (query string filters optional: date, location, eventType, upcomingOnly)          | 200 OK with an array of events.                                                                                                                             |
| GET         | /api/events/{id}        | Returns the full detail of a single event.                                                                | Any (authenticated) | None                                                                                   | 200 OK with the event. 404 Not Found.                                                                                                                       |
| POST        | /api/events             | Creates a new event owned by the logged-in Organiser.                                                     | Organiser           | { eventName, description, eventDate, location, distanceKm, eventType, bannerImageUrl } | 201 Created with the new event id. 400 Bad Request. 403 Forbidden.                                                                                          |
| PUT         | /api/events/{id}        | Updates an event that belongs to the logged-in Organiser.                                                 | Organiser (owner)   | { eventName, description, eventDate, location, distanceKm, eventType, bannerImageUrl } | 200 OK with the updated event. 400 Bad Request. 403 Forbidden. 404 Not Found.                                                                               |
| DELETE      | /api/events/{id}        | Removes an event that belongs to the logged-in Organiser.                                                 | Organiser (owner)   | None                                                                                   | 204 No Content. 403 Forbidden. 404 Not Found.                                                                                                               |
| GET         | /api/events/my          | Lists the events the logged-in Organiser created, each with its total number of enrolments.               | Organiser           | None                                                                                   | 200 OK with an array of events and enrolment counts. 401 Unauthorized. 403 Forbidden.                                                                       |
| POST        | /api/events/{id}/banner | Uploads a banner image for an event owned by the logged-in Organiser and stores it in Azure Blob Storage. | Organiser (owner)   | multipart/form-data with a single image file named bannerFile                          | 200 OK with the updated event. 400 Bad Request for a missing file, an unsupported type or a file over 5 MB. 401 Unauthorized. 403 Forbidden. 404 Not Found. |

## Categories

| HTTP Method | Route                            | Description                                                                    | Role Required       | Request Body                                 | Expected Response                                                     |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------ | ------------------- | -------------------------------------------- | --------------------------------------------------------------------- |
| GET         | /api/events/{eventId}/categories | Lists the categories available for an event.                                   | Any (authenticated) | None                                         | 200 OK with an array of categories.                                   |
| POST        | /api/events/{eventId}/categories | Adds an age or distance category to an event owned by the logged-in Organiser. | Organiser (owner)   | { categoryName, minAge, maxAge, distanceKm } | 201 Created with the new category id. 400 Bad Request. 403 Forbidden. |
| PUT         | /api/categories/{id}             | Updates a category belonging to one of the Organiser's events.                 | Organiser (owner)   | { categoryName, minAge, maxAge, distanceKm } | 200 OK with the updated category. 403 Forbidden. 404 Not Found.       |
| DELETE      | /api/categories/{id}             | Removes a category from one of the Organiser's events.                         | Organiser (owner)   | None                                         | 204 No Content. 403 Forbidden. 404 Not Found.                         |

## Event Enrolments

| HTTP Method | Route                            | Description                                                                    | Role Required     | Request Body   | Expected Response                                                                                                   |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------ | ----------------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| POST        | /api/events/{eventId}/enrolments | Enrols the logged-in Participant into the event under a chosen category.       | Participant       | { categoryId } | 201 Created with the new enrolment. 400 Bad Request. 403 Forbidden. 409 Conflict if already enrolled in that event. |
| GET         | /api/enrolments/my               | Lists the logged-in Participant's own enrolments and their status.             | Participant       | None           | 200 OK with an array of enrolments.                                                                                 |
| GET         | /api/events/{eventId}/enrolments | Lists every Participant enrolled in an event owned by the logged-in Organiser. | Organiser (owner) | None           | 200 OK with an array of enrolments. 403 Forbidden.                                                                  |

## Results

| HTTP Method | Route                                | Description                                                                                                                                             | Role Required                  | Request Body                      | Expected Response                                                                                                 |
| ----------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| POST        | /api/enrolments/{enrolmentId}/result | Captures a finish time and position for a Participant's enrolment, once the Organiser's event has concluded.                                            | Organiser (owner of the event) | { finishTime, finishingPosition } | 201 Created with the new result. 400 Bad Request. 403 Forbidden. 404 Not Found.                                   |
| GET         | /api/results/my                      | Lists the logged-in Participant's own race results across all completed events, including finishing position and the number of finishers in that event. | Participant                    | None                              | 200 OK with an array of results.                                                                                  |
| PUT         | /api/enrolments/{enrolmentId}/result | Corrects the finish time or position already captured for an enrolment.                                                                                 | Organiser (owner of the event) | { finishTime, finishingPosition } | 200 OK with the updated result. 400 Bad Request. 403 Forbidden. 404 Not Found if the enrolment has no result yet. |
